What is Nigh?

Nigh is a proximity-based network for real life. IRL Drops are spontaneous, in-person moments — a happy hour, a pop-up, a run club, a last-minute set — that you only get by showing up. No endless feed, no algorithm. Just real moments, from people and places you already follow.
