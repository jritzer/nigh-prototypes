New"You've been invited to Nigh" → install → onboard, connected to the inviter
ExistingOpens the app and connects them to the inviter
Dead"This invite was revoked or already used"
Lifespan: person-bound — long-lived (optional cap / revoke).  Attribution: top-of-funnel "joined from you" → feeds Community Impact.
group.nigh.com/<code>
An invite to join a Group / List
NewOnboard → join Nigh → join the group, connected to the inviter
Existing"You've been invited to join [Group]" → accept to become a member
Dead"You're no longer able to join this group"
Lifespan: group-bound — valid while the group exists.  Why it matters: membership makes them eligible for that group's gated Drops.

Groups are join-by-invite only (v1)

No one is ever added to a group automatically. Sharing a group-gated drop.nigh.com link lets someone see the Drop, but they stay blocked from reserving until they join the group via a group.nigh.com link. (Public, open-join groups may come later — not in v1.)

Code generator · Crockford Base32

Alphabet omits I L O U (lookalikes + obscenity guard). Decoding also folds I L 1 → 1 and O → 0, so a mistyped link still resolves.

drop.nigh.com/— 
// Crockford Base32 — no I, L, O, U
const ALPHABET = "0123456789ABCDEFGHJKMNPQRSTVWXYZ";

// generate an n-char Drop code
function makeCode(n = 6) {
  const bytes = crypto.getRandomValues(new Uint8Array(n));
  let out = "";
  for (const b of bytes) out += ALPHABET[b & 31]; // 0–31
  return out;
}

// normalize on the way back in (forgiving decode)
function normalize(code) {
  return code.toUpperCase()
    .replace(/[IL]/g, "1") // I, L → 1
    .replace(/O/g, "0");  // O → 0
}
